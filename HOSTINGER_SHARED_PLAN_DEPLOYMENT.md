# Hostinger Shared Plan Deployment (PHP Migration)

This project is now converted to PHP for Hostinger shared hosting compatibility.

## 1) Prepare files locally

Upload these required items only:

- `.htaccess`
- `index.php`
- `composer.json`
- `.env` (create from `.env.example`)
- `config/`
- `src/`
- `templates/`
- `static/`

Ready-to-upload clean package generated by this migration:

- `fcw_php_hostinger_release_*.zip` (latest version in project root)

## 2) Upload to Hostinger

1. Open `hPanel -> Websites -> Manage -> File Manager`.
2. Go to domain root (`public_html` or `/domains/fcw.co.in/public_html`).
3. Upload your application files/folders listed above.
4. Ensure old Python files are not in the web root.

## 3) Configure environment

1. Duplicate `.env.example` to `.env`.
2. Set values:
   - `DATABASE_URL`
   - `ADMIN_PIN`
   - `SMTP_SERVER`
   - `SMTP_PORT`
   - `SENDER_EMAIL`
   - `SENDER_PASSWORD`
   - `ADMIN_EMAIL`
3. Keep `AUTO_CREATE_TABLES=true` for first deploy.

`DATABASE_URL` formats supported by this codebase:

- PostgreSQL (Neon): `postgresql://USER:PASSWORD@HOST/DBNAME?sslmode=require`
- MySQL (Hostinger shared plan recommended): `mysql://USER:PASSWORD@HOST:3306/DBNAME?charset=utf8mb4`

## 4) Install PHP dependencies (PHPMailer)

From Hostinger SSH terminal:

```bash
cd ~/domains/fcw.co.in/public_html
composer install --no-dev --optimize-autoloader
```

If `composer` command is unavailable:

```bash
php -r "copy('https://getcomposer.org/installer', 'composer-setup.php');"
php composer-setup.php
php composer.phar install --no-dev --optimize-autoloader
```

## 5) Permissions

Ensure web files are readable by the web server. Typical default user permissions in Hostinger are enough.

## 7) Post-deploy hardening

After first successful boot and table creation:

- Set `AUTO_CREATE_TABLES=false` in `.env`

Optional:

- Set `APP_DEBUG=false` (recommended for production)
- Change `ADMIN_PIN` to a strong value
- Use SMTP app-password (not normal email password)

## 8) Troubleshooting

### Blank page / 500 error

- Check `.env` values
- Verify `vendor/autoload.php` exists (composer install done)
- Review Hostinger error logs in hPanel

### `/health/db` fails

- Verify `DATABASE_URL`
- Check available PDO drivers:
  - `php -m | grep -Ei 'pdo|pgsql|mysql'`
- If `pdo_pgsql` is missing on shared hosting, switch to MySQL `DATABASE_URL` format above.

### Contact/assessment email not delivered

- Check SMTP credentials
- Verify sender account app-password / SMTP access

## 9) Notes

- This setup uses Apache rewrite through `.htaccess`.
- Hostinger migration wizard rejects `.py` files; this PHP migration bypasses that limitation.
